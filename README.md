### About Me

I spent five years building production web applications — React and Next.js on the
front, **Go** and **Python** APIs behind them — and I now write the coding tasks and
tests used to train and evaluate AI agents.

Most of that work comes down to one question: did this actually get fixed, or does it
just look fixed? I take a real repository, plant a bug, write the gold solution, and
build the grader that decides whether a fix is real. The grader is the hard part. It
has to pass any reasonable solution and reject everything else — including the ones
that make the symptom disappear without touching the cause.

20+ task environments built this way, 4 approved through both automated and human review.
